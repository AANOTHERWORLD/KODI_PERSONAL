## Impact on the build

**None breaking or degrading.** Checked against the released zips (TMDb Helper 6.22.7, SkinVariables 2.3.11, AF3 3.5.7):
- All tmdbhelper_settings.json keys exist in 6.22.7 settings.xml (`target_addon` is the file's own routing key). sync_provider_watched / watchlist = trakt valid in catalog.py; `never` unchanged. `invalidate_sync=watched` still in invalidator.py. sync.trakt and sync.mdblist unchanged, so `token`, `apikey`, `TraktIsAuth` and the calendar limit anchor are as verified yesterday.
- TMDb Helper routing, items mapping and sync code unchanged apart from the two fanart factories, so lists.json and autoplay routes still resolve. EpisodeItemMapper patch anchor present once in 6.22.7 mapper_standard.py and EpisodeItemMapper still has no get_params.
- AF3 ratings: skin_settings.json sets `customrating.movies.item01/02` and `customrating.tvshows.item01/02` to Trakt and Metacritic. In 3.5.7 these strings only feed the one-time migration; the migration and the new default menus both put Trakt then Metacritic first, so the result is the same whether the service writes them before or after the migration. Movies gain Oscar wins as a third rating when available (new upstream behaviour, not a regression). The ratings menus are written to SkinVariables nodes as `skinvariables-shortcut-ratings*.json`; the service's `_is_managed_node` only prunes 11xx and moreprov files, so it leaves them alone.
- AF3 hubs file, migrate-hubs files and the setup wizard conditions in Home.xml unchanged. Widget generator templates add Weather-only rules with `True` defaults, so the build's widget nodes render as before. 51 of 52 skin_settings ids still referenced by AF3 (`skin.settingslevel` pre-existing). Background.ExtraFanart toggle moved, not removed; the build does not set it.
- Floors resolve through repository.aanotherworld dirs: SkinVariables 2.3.11 and TMDb Helper 6.22.7 in jurialmunkey omega; resource.images.arctic.splash 1.1.1 in jurialmunkey repo/ (aggregated). weathericons.white and studios.coloured floors unchanged.
