## Impact on the build

None today (nothing released). One upstream incompatibility to watch:
- sync.trakt 1.2.9 `identifiers/database.py` calls `self.access.connection.open()` in `is_queried()` and `get_item()`. TMDb Helper HEAD no longer has `DatabaseAccess.connection`, so if TMDb Helper ships this source without a matching sync.trakt release, Trakt ID lookups would raise AttributeError. That would hit the build's Trakt lists (calendar episodes, `trakt_nextepisodes` widgets, watchlists). This is an upstream pairing issue, not something the build can patch; sync.trakt's other database use (`get_database()` with `contextlib.closing`) still works against HEAD.
- sync.mdblist 1.1.4: no use of `DatabaseAccess.connection`, `connection=` kwargs or SimpleCache internals. Compatible.
- No TMDb Helper settings.xml, sync provider catalog, routes, `sync/invalidator.py` or `items/directories/mapper_standard.py` changed, so the EpisodeItemMapper patch, `invalidate_sync=watched`, provider ids and `info=` routes still hold. The service reads only Kodi's own settings.db and Textures db, never TMDb Helper's databases.
- jurialmunkey 0.2.38 floor will resolve from the jurialmunkey omega dir, which repository.aanotherworld aggregates. Nothing in SkinVariables, AF3 or the providers uses the removed SimpleCache private methods.
