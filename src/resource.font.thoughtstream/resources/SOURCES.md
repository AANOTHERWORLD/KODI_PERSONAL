# ThoughtStream font sources

The .ttf binaries are committed in this `resources/` folder and referenced as
`resource://resource.font.thoughtstream/<file>.ttf`, matching the way Arctic
Fuse 3 references its own font resource addon.

All three are SIL Open Font License 1.1, which permits redistribution. The
license texts are committed alongside as OFL-LibreBaskerville.txt and
OFL-Inter.txt.

| File | Family and weight | Upstream OFL source |
| --- | --- | --- |
| LibreBaskerville-Bold.ttf | Libre Baskerville 700 | github.com/impallari/Libre-Baskerville, fonts/ttf |
| Inter-Regular.ttf | Inter 400 | github.com/rsms/inter, v4.1 release, extras/ttf |
| Inter-SemiBold.ttf | Inter 600 | github.com/rsms/inter, v4.1 release, extras/ttf |
